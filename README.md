# Excel 研习室 · 公开网页版

11 套研究生 Excel 题库，共 1628 题，含评分、自动保存、错题本、已掌握历史及进度备份恢复。

## 手机使用

访问 GitHub Pages 发布的网址，选择试卷即可开始。可以从手机浏览器菜单添加到主屏幕。

练习采用百分制：答对题数 / 本次题数 × 100；多选全部选对才得分，未答 0 分。此分数不是原网站正式考试题型权重。

每人的作答进度和错题仅保存在自己的浏览器中，不上传服务器或 GitHub；换设备可通过首页备份、导入恢复。不同网址之间不会自动同步记录。

## 静态部署

在仓库 Settings → Pages 中选择 Deploy from a branch，分支 main，目录 / (root)，即可发布。无需安装依赖，无需后端。

index.html 是首页；papers/ 为每套试卷的独立入口；wrongs.html 为合并错题本；materials/ 为原始 Excel 素材。所有题图均已嵌入页面。

本仓库是经用户授权的公开网页版，不包含任何人的答题记录、登录凭据或备份文件。题库与答案依据用户已有素材，用于学习练习。
